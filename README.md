# God Game Plugin (name tbd)
Plugin providing the basic foundationf or an old-school _Populous_, _Black & White_, etc. style of God Game where the player oversees the progress/destruction of an initially small village.

## Current State (🚧)
There is a very structure and set of systems/mechanics at this point; at its core the game is working towards:

* **Village** -- Initially one small village with a handful of active **Villagers**.
* **Villagers** -- A minimal AI which executes behavior over the course of a 24h game sim and bases its decisions on their **Needs**; in code each need is tied to a native gameplay tag and is bounded in the inclusive range of `[0.0, 1.0]`. The higher the need, the more urgently it needs to be satisfied through player intervention.
  * **Faith** -- This is the most critical "need" to growing the village and the player's power.
  * **Hunger**
  * **Rest**
  * **Fear**
  * **Socialization**
* **Miracles** -- These are "spells" that the player can cast to affect the game sim and require **Influence** to cast (which is generated by Villagers that have faith in the player).

## Dependencies
### JoyCore Plugin (🚧)
This is a rough game setup that has a secondary objective of furthering progress on [**JoyCore**](https://github.com/trentpolack/JoyCore), a general game support plugin for Unreal Engine 5.
